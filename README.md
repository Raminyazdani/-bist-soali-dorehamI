# روی پیشونی! — بیست‌سؤالی دورهمی

**[باز کردن نسخهٔ فعلی بازی](https://rooye-pishooni.vercel.app/)**

تغییرهای این شاخه هنوز مرج نشده‌اند؛ نسخهٔ زیر تا اجازهٔ کاربر و تکمیل اتصال ذخیره‌سازی، روی آدرس اصلی منتشر نمی‌شود.

بازی فارسی برای گوشی، ۲ تا ۱۲ نفر. یک نفر لابی می‌سازد، بقیه با کد شش‌رقمی وارد می‌شوند. حساب، نصب برنامه، کلید سرویس و لپ‌تاپ لازم نیست.

لابی روی سرور نگه‌داری می‌شود و به باز بودن گوشی سازنده وابسته نیست. برای پیدا کردن عکس می‌توانی از بازی بیرون بروی؛ بقیه همچنان کارت می‌سازند. وقتی برگردی، همان لابی و کارت‌ها نمایش داده می‌شود. اگر خودِ بازیکنِ نوبت یا داور بیش از ۲۰ ثانیه قطع شود، فقط نوبت جاری مکث می‌شود.

## بازی

- مدیر تعداد کارت هر نفر را بین ۱ تا ۲۰ تعیین می‌کند. همه آماده می‌شوند و مدیر کارت‌سازی را شروع می‌کند.
- متن هر کارت اجباری است؛ عکس اختیاری. کارت‌ها هنگام نوشتن برای بقیه پنهان‌اند.
- وقتی همه آماده‌اند، کارت‌ها و ترتیب نوبت‌ها تصادفی می‌شوند. کارت خودت به تو نمی‌رسد؛ سهم هر نفر از نویسنده‌های دیگر تا حد ممکن برابر است. مثلاً در جمع چهارنفری با سه کارت، از هر نفر دیگر یک کارت می‌گیری. هر کارت دقیقاً یک‌بار بازی می‌شود. هر نفر به تعداد کارت‌ها نوبت دارد.
- نفر بعدی در ترتیب، داور نوبت است. بقیه هم کارت، زمان و شمارنده را می‌بینند. مدیر می‌تواند داور را تغییر دهد.
- داور شروع را می‌زند؛ سه ثانیه فرصت داری گوشی را بالای سرت بگیری. سپس کارت نمایش داده می‌شود و زمان شروع می‌شود.
- هر سؤال یا حدس مستقیم را داور یک‌بار ثبت می‌کند. خطا قابل برگشت است. حدس درست، به تعداد سؤال‌های باقی‌مانده امتیاز دارد.
- بعد از سؤال بیستم هنوز می‌توان جواب آخر را ثبت کرد؛ شکست را داور ثبت می‌کند. شکست صفر امتیاز دارد. ثبت برد یا باخت، حذف بازیکن، بستن لابی و شروع بازی تازه پنجرهٔ تأیید دارند؛ ثبت و برگرداندن سؤال بدون تأیید انجام می‌شود.
- مکث از زمان حساب نمی‌شود. امتیاز بیشتر بالاتر است؛ در تساوی، مجموع زمان همهٔ نوبت‌های تمام‌شده (برد و باخت) کمتر. تساوی دقیق رتبهٔ مشترک دارد.
- مدیر از منوی ⋯ می‌تواند بازیکن‌ها را حذف کند. حذف بعد از مرحلهٔ لابی با تأیید، بازی فعلی را پاک می‌کند و جمع باقی‌مانده به لابی برمی‌گردد.
- مدیر و سازنده می‌توانند «بستن لابی و خروج» را بزنند؛ همه به صفحهٔ اول برمی‌گردند. «خروج از لابی» در مرحلهٔ لابی فقط خودت را خارج می‌کند؛ اگر مدیر باشی، مدیریت به نفر بعد می‌رسد. «بستن لابی» با تأیید، همه را خارج می‌کند.
- در پایان، جدول امتیاز و نویسندهٔ همهٔ کارت‌ها نمایش داده می‌شود. بازی دوباره، کارت‌ها و امتیازها را پاک می‌کند و همان جمع می‌ماند.

## ساختار

Vite و JavaScript ساده، رابط فارسی و APIهای کوچک روی Vercel Functions، با ذخیرهٔ خصوصی Vercel Blob. گوشی‌ها مستقیم با سرور ارتباط دارند و وضعیت حدود هر ۱٫۶ ثانیه هماهنگ می‌شود؛ ساعت روی هر گوشی روان نمایش داده می‌شود. هیچ گوشی، لپ‌تاپ یا سرور سوکت جداگانه‌ای میزبان جمع نیست.

وضعیت لابی با خواندن مستقیم آخرین نسخه و نوشتن شرطی ETag ذخیره می‌شود. کنترل نسخه، شناسهٔ نوبت و شناسهٔ درخواست جلوی تغییر همزمانِ اشتباه و امتیاز تکراری را می‌گیرند. کارت‌های آینده برای بقیه ارسال نمی‌شوند. عکس‌ها خصوصی‌اند و API عکس، عضویت و قابل‌دیدن‌بودن کارت را بررسی می‌کند.

## توسعه و تست

```sh
npm ci
npm run build
npm run dev
npm test
node test/browser-e2e.mjs
node test/photo-e2e.mjs
node test/lobby-e2e.mjs
node test/background-e2e.mjs
```

اجرای محلی و تست‌ها از ذخیره‌سازی واقعی روی دیسک در `test-output/` استفاده می‌کنند. کد مستقرشده همیشه از Vercel Blob استفاده می‌کند؛ هیچ برگشت خودکاری به حافظهٔ یک تابع یا گوشی وجود ندارد. برای تست روی پیش‌نمایش، `E2E_URL` را به آدرس همان پیش‌نمایش بدهید. نتیجه‌های تأییدشده در `VERIFICATION.md` و وضعیت ادامهٔ کار در `STATUS.md` است.

## استقرار

Vercel: Vite، `npm run build`، خروجی `dist`. یک Blob store با دسترسی **private** به پروژه وصل کنید تا `BLOB_READ_WRITE_TOKEN` فقط در محیط سرور تنظیم شود. برای این شاخه ابتدا Preview را تنظیم و تست کنید؛ Production بعد از اجازهٔ مرج کاربر. کلید نباید در کد، گیت، رابط یا متغیر `VITE_` قرار بگیرد.

لابی‌های قبلی که روی گوشی میزبان بودند به این سرور منتقل نمی‌شوند. بعد از انتشار این نسخه یک لابی تازه بسازید. اینترنت برای بازی لازم است؛ هیچ حساب یا نصب برنامه‌ای برای بازیکن‌ها لازم نیست.
