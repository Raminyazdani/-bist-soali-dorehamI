# روی پیشونی! — بیست‌سؤالی دورهمی

**[باز کردن بازی](https://rooye-pishooni.vercel.app/)**

بازی فارسی برای گوشی، ۲ تا ۱۲ نفر. یک نفر لابی می‌سازد، بقیه با کد شش‌رقمی وارد می‌شوند. حساب، نصب برنامه، کلید سرویس و لپ‌تاپ لازم نیست.

صفحهٔ بازی روی گوشی **سازندهٔ لابی باید باز و روشن بماند**؛ آن گوشی اتصال جمع و وضعیت بازی را نگه می‌دارد. وای‌فای مشترک پیشنهاد می‌شود. پس از رفرش، بازی از حافظهٔ همان مرورگر برمی‌گردد؛ در حین نوبت مکث می‌شود تا داور ادامه دهد. پاک‌کردن داده‌های مرورگر سازنده، اطلاعات همان لابی را پاک می‌کند.

## بازی

- مدیر تعداد کارت هر نفر را بین ۱ تا ۲۰ تعیین می‌کند. همه آماده می‌شوند و مدیر کارت‌سازی را شروع می‌کند.
- متن هر کارت اجباری است؛ عکس اختیاری. کارت‌ها هنگام نوشتن برای بقیه پنهان‌اند.
- وقتی همه آماده‌اند، کارت‌ها و ترتیب نوبت‌ها تصادفی می‌شوند. کارت خودت به تو نمی‌رسد؛ هر کارت دقیقاً یک‌بار بازی می‌شود. هر نفر به تعداد کارت‌ها نوبت دارد.
- نفر بعدی در ترتیب، داور نوبت است. بقیه هم کارت، زمان و شمارنده را می‌بینند. مدیر می‌تواند داور را تغییر دهد.
- داور شروع را می‌زند؛ سه ثانیه فرصت داری گوشی را بالای سرت بگیری. سپس کارت نمایش داده می‌شود و زمان شروع می‌شود.
- هر سؤال یا حدس مستقیم را داور یک‌بار ثبت می‌کند. خطا قابل برگشت است. حدس درست، به تعداد سؤال‌های باقی‌مانده امتیاز دارد.
- بعد از سؤال بیستم هنوز می‌توان جواب آخر را ثبت کرد؛ شکست را داور ثبت می‌کند. شکست صفر امتیاز دارد.
- مکث از زمان حساب نمی‌شود. امتیاز بیشتر بالاتر است؛ در تساوی، مجموع زمان کمتر. تساوی دقیق رتبهٔ مشترک دارد.
- در پایان، جدول امتیاز و نویسندهٔ همهٔ کارت‌ها نمایش داده می‌شود. بازی دوباره، کارت‌ها و امتیازها را پاک می‌کند و همان جمع می‌ماند.

## ساختار

Vite و JavaScript ساده، میزبانی ثابت روی Vercel، اتصال WebRTC با PeerJS و سرویس عمومی PeerJS فقط برای پیدا کردن گوشی‌ها. داده‌های بازی روی اتصال رمزگذاری‌شدهٔ گوشی‌ها منتقل می‌شود. وضعیت اصلی روی گوشی سازنده و در IndexedDB ذخیره می‌شود. مدیریت لابی را می‌توان منتقل کرد؛ گوشی سازنده همچنان اتصال را نگه می‌دارد.

یک صف درخواست روی گوشی سازنده، همراه با کنترل نسخه، شناسهٔ درخواست و شناسهٔ نوبت، جلوی شمارش تکراری و تغییرات همزمان را می‌گیرد. کارت‌های آینده برای سایر گوشی‌ها ارسال نمی‌شوند. عکس‌ها جدا ذخیره و هنگام نیاز منتقل می‌شوند.

برای جمع دوستانه طراحی شده است. اینترنت و دسترسی به سرویس عمومی اتصال لازم است. اگر یک شبکه اتصال مستقیم را مسدود کند، از وای‌فای مشترک استفاده کنید. این نسخه حساب، پرداخت، هوش مصنوعی یا سرویس دیتابیس ندارد.

## توسعه

```sh
npm ci
npm run dev
npm test
npm run build
node test/browser-e2e.mjs
```

تست‌ها قوانین، تخصیص کارت، امتیاز، همزمانی و تکرار درخواست‌ها را بررسی می‌کنند. تست مرورگر باید مسیر واقعی چند بازیکن، عکس، نوبت‌ها، بازگشت و بازی مجدد را بررسی کند. وضعیت واقعی تأییدها و کارهای باقی‌مانده در `STATUS.md` است.

برای استقرار، ریپو را به Vercel وارد کنید: Vite، دستور `npm run build` و پوشهٔ خروجی `dist`. هیچ متغیر محیطی لازم نیست.
